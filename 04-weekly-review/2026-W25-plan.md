# 2026-W25 — Training Plan

## Weekly Intent
- Body status: user reports full-body readiness after 2 rest days.
- Shoulder status: user reports right shoulder recovered after 1 rest day.
- Main goal: increase volume on exercises with good training history, while using lower-risk form-learning blocks for exercises that still need practice.
- Guardrail: more volume does not mean chasing failure. Most working sets should stay around RPE 7-8, with only selected final sets allowed to approach RPE 8.5 if form is clean.

## Volume Rules
- Increase volume only on "green-light" exercises:
  - V-handle / Neutral Pulldown at 18kg.
  - Chest Supported Row Machine around 10kg.
  - Hip Abduction Machine.
  - Leg Press with low-foot quad bias.
  - Calf Raise with slow ROM.
- Keep form-learning exercises conservative:
  - Straight-bar Lat Pulldown above 18kg.
  - Leg Curl at 17lbs.
  - Cable Lateral Raise at 5kg.
  - Pec Fly / Chest Press when shoulder support appears.
  - Machine Preacher Curl after heavy pulling.
- Hard stop rules:
  - Stop an exercise if sharp joint pain appears.
  - Stop curls if neck/trap support appears.
  - Stop chest/fly/cable work if shoulder support appears.
  - No forced burnout partials this week unless explicitly planned as one final controlled set.

## 2026-06-15 — Back / Lat MMC
- Main focus: lats, mid-back, inner-back.
- Target duration: 60-75 min.
- Target RPE: 7-8.
- Main win condition: back does the work, biceps does not steal the session.

| Exercise | Sets x Reps | Target Load | Target RPE | Notes |
|---|---:|---:|---:|---|
| Warm-up Pulldown | 2 x 15 | very light / 15-18kg | 4-5 | Shoulder down, ribs down, feel stretch under armpit. |
| Neutral / V-handle Pulldown | 4 x 12-15 | 18kg | 7 | Green-light exercise. Add 1 set vs last time if form stays clean. |
| Chest Supported Row Machine | 4 x 12-15 | 10kg | 7 | Green-light exercise. Chest glued to pad, elbows lead. |

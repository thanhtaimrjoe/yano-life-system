## 1. Japanese Grammar Issues

### Identified Issues (2026-05-21 - Session 1 Prep)

| Issue | Example | Correction | Pattern |
|-------|---------|------------|---------|
| を vs の confusion | Fresher BrSE**を**就職中です | Fresher BrSEの仕事**を**探しています | Particle usage |
| Noun modification | 1年ほど**の**ITコミュニケーター | ITコミュニケーター**として**1年ほど | として vs の |
| Passive form | 商品に紐付け**の**資料 | 商品に紐付け**られた**資料 | Passive conjugation |
| Purpose expression | 検索できる**ため** | 検索できる**ように** | ため vs ように |

### Root Cause Analysis
- **Pattern:** Particle confusion (を/の/として)
- **Why:** Translating from Vietnamese/English structure directly
- **Impact:** Sounds unnatural to native speakers, reduces credibility

### Action Items
- [ ] Review particle usage rules (を/の/に/として)
- [ ] Practice 10 sentences with correct particles daily
- [ ] Read answers out loud and self-correct
- [ ] Get feedback from native speaker (if possible)

### Progress Tracking
- **Week 1:** Identify patterns, create correction list
- **Week 2:** Practice daily, reduce errors by 50%
- **Week 3:** Natural usage, 8/10 accuracy

| Question | Vague Answer | Specific Answer Needed |
|----------|--------------|------------------------|
| Why BrSE? | "プロジェクトの中で経験を積みたい" | "要件定義や設計フェーズから関わり、システム全体を理解したい" |
| What you bring? | Generic skills list | Specific KINKEN examples + QA mindset |
| Long-term goal? | "Senior BrSE" | "Senior BrSE with expertise in [specific domain]" |

### Root Cause Analysis
- **Pattern:** Generic answers without concrete examples
- **Why:** Trying to cover everything → ends up saying nothing specific
- **Impact:** Interviewer cannot assess real capability

### STAR Method Practice Needed
**S**ituation → **T**ask → **A**ction → **R**esult

Example:
```
Vague: "I found bugs in KINKEN project"

STAR:
S: During KINKEN testing phase, search results were inconsistent
T: My task was to identify root cause and document for dev team
A: I analyzed search logs, reproduced the bug, created detailed test case with screenshots
R: Dev team fixed the bug in 2 days, search accuracy improved by 15%
```

### Action Items
- [ ] Rewrite motivation answer with specific examples
- [ ] Prepare 3 STAR stories from KINKEN project
- [ ] Practice explaining "what you bring" with concrete evidence
- [ ] Add metrics/numbers where possible (time saved, bugs found, accuracy improved)

### Progress Tracking
- **Week 1:** Identify vague answers, rewrite with specifics
- **Week 2:** Practice STAR stories in mock interviews
- **Week 3:** Natural storytelling with concrete examples

| Context | Informal | Formal |
|---------|----------|--------|

| English interview | "grow up my skill" | "develop my skills" |
| Vietnamese | "cọ sát" | "tích lũy kinh nghiệm" |

### Root Cause Analysis
- **Pattern:** Comfortable with casual language, less practice with formal register
- **Why:** Daily communication is informal, interview context is formal
- **Impact:** Sounds unprofessional, reduces credibility

### Register Awareness Checklist
- [ ] Avoid contractions (wanna → want to, gonna → going to)
- [ ] Use formal vocabulary (get → obtain, show → demonstrate)
- [ ] Complete sentences (no fragments)
- [ ] Professional tone (not too casual, not too stiff)

### Action Items

- [ ] Record formal vs informal versions and compare

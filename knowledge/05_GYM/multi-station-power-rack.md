This is a more advanced training area compared to selectorized machines and will likely become an important progression step later in the comeback phase.

## Setup & Adjustments

* Key setup points:

  * Adjust safety bars before using barbell movements.
  * Ensure barbell height matches movement (bench/squat/OHP).
  * Use manageable load only.
  * Prioritize stable stance and core bracing.

* Common adjustments:

  * J-hook height
  * Safety pin height
  * Cable attachment height
  * Bench placement

* Recommended starting position:

  * Neutral spine
  * Core active nhẹ
  * Chest open naturally
  * Avoid exaggerated lumbar arching

## Technique & Cues

* Main form cues:

  * Tall posture, not over-arched posture
  * Ribs down
  * Control the eccentric
  * Move with intention, not momentum

* Mind-Muscle Connection tips:

  * Start lighter than ego expects.
  * Maintain stable torso before increasing load.
  * Focus on smooth movement patterns.

* Tempo recommendations:

  * Controlled eccentric (2-3s)
  * Smooth concentric
  * Pause briefly in stable positions

* Breathing:

  * Light brace before movement
  * Controlled exhale during exertion

## Common Mistakes to Avoid

* Ego loading too early during comeback phase
* Excessive lumbar arching
* Using momentum instead of muscular control
* Skipping safety setup
* Chasing heavy barbell work before movement quality is stable

## Progressions & Variations

* Beginner friendly options:

  * Smith machine squat
  * Assisted pull-up variations
  * Light barbell Romanian deadlift
  * Empty bar bench press
  * Cable rows / cable pulldowns

* Advanced variations:

  * Barbell squat
  * Conventional deadlift
  * Bench press
  * Overhead press
  * Weighted pull-ups

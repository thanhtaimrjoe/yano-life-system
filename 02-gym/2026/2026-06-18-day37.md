# Day 37 — Lower B / Glute + Hamstring

## Session Summary
- Hôm nay đổi Hip Thrust Machine sang Romanian Deadlift để tập trung kích hoạt hamstring và glutes qua pattern hinge.
- Buổi tập dễ mệt hơn dự kiến, đặc biệt ở RDL với nhịp tim lên khoảng 115–120 BPM.
- Hamstring được kích hoạt tốt qua RDL + Leg Curl.
- Hip Abduction vào đúng mông trên và mông ngoài (upper/outer glute) rõ rệt, đặc biệt set cuối tăng tạ lên 25kg.
- Calf chỉ làm đúng 1 set rồi chủ động dừng lại để bảo toàn recovery, do ngày 16 calf đã bị pump rất mạnh ở RPE 9.

## Key MMC / Form Insights
- RDL:
  - 7.5kg DB đủ để tạo hamstring burn.
  - 15 reps làm tim đập nhanh hơn machine isolation.
  - Lần sau nên cân nhắc 3 x 10-12 để giữ form và nhịp thở tốt hơn.

- Leg Curl:
  - 17lbs vào hamstring tốt nhưng RPE lên 8 ngay.
  - Người hơi run ở set 2 là dấu hiệu fatigue, dừng tại 2 set là hợp lý.

- Hip Abduction:
  - Lean nhẹ 10-20° giúp ăn mông ngoài/mông trên rõ hơn.
  - Không cần mở max quá mức; mở 80-90% ROM sạch sẽ tốt hơn.
  - 25kg x16 RPE 8 tạo stimulus tốt, nhưng không nên thêm set sau đó.

- Calf Raise:
  - Calf pump/nổi cục rõ sau 20kg x15.
  - Dừng tại 1 set là quyết định tốt vì calf vừa bị kích mạnh ngày 16/06.

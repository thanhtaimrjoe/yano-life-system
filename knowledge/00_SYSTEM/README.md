# 00_SYSTEM

`00_SYSTEM/` is control layer for AI-managed knowledge inside `knowledge/`.

Its purpose is to help any AI agent understand:
- what `knowledge/` is for
- how information should be organized
- how notes should be maintained over time
- how to make consistent, reversible structural decisions

## Important Files

- `CORE.md`
  - defines operating principles, boundaries, and AI role
  - use this first to understand non-negotiables and decision priorities

- `Knowledge-Organization.md`
  - defines folder scope, naming rules, metadata suggestions, linking strategy, and maintainability standards
  - use this when deciding where notes belong and how they should be shaped

- `Workflows.md`
  - defines practical operating procedures for intake, normalization, retrieval, synthesis, refactor, archive, and maintenance
  - use this when acting on user requests or doing autonomous cleanup

## How AI Should Use This Folder

Recommended order:
1. Read `CORE.md` for global rules and boundaries.
2. Read `Knowledge-Organization.md` before moving or creating durable knowledge files.
3. Read `Workflows.md` before normalization, synthesis, retrieval, or large refactors.

Use `00_SYSTEM/` especially when:
- importing rough material into `knowledge/`
- reorganizing folders or files
- deciding whether to create, merge, move, or archive notes
- answering user questions from repository knowledge
- creating higher-level synthesis notes

This folder should stay concise, stable, and AI-oriented.

# Exercises

## 1. Seated Chest Press

### Working Sets
- Set 1: 15 reps
- Set 2: ~15 reps
- Set 3: 18 reps

### Notes
- Ban đầu cảm nhận ngực khoảng 40%
- Điều chỉnh:
  - mở ngực hơn
  - setup tay ngang ti
  - kiểm soát rep tốt hơn
- Cảm nhận:
  - ăn ngực trên
  - vùng sát nách active rõ
- Không tăng tạ vì focus:
  - form
  - MMC (mind-muscle connection)

### Key Learning
- “Form PR > Weight PR”
- Giữ weight vừa phải giúp:
  - cảm nhận cơ rõ hơn
  - movement sạch hơn

## 2. Shoulder Press Machine

### Weight
- 20 lbs

### Working Sets
- ~3 sets × 15 reps

### Notes
- Set đầu:
  - hạ quá sâu
  - vai bị overload mạnh
- Sau đó chỉnh:

  - ROM an toàn hơn
- Không tăng lên 30 lbs để giữ quality reps

### Key Learning
- ROM phù hợp quan trọng hơn ego weight
- Vai phản hồi tốt khi:
  - không xuống quá sâu
  - kiểm soát eccentric

## 3. Seated Dip Machine

### Weight Progression
- Set đầu: 11 lbs
- Sau đó: 22 lbs

### Working Sets
- ~3 sets
- Set cuối: 15 reps @22 lbs

### Notes
- Cảm nhận tay sau rất rõ
- Vai chỉ support nhẹ
- Pause 0.5s ở bottom làm:
  - tăng tension
  - tay run nhẹ
  - tricep active rõ hơn

### Form Focus
- Vai hạ xuống
- Không shrug
- ROM vừa phải
- Không lockout cứng khuỷu tay

### Key Learning
- Tempo + pause tạo tension tốt hơn tăng tạ
- Dip machine bắt đầu quen movement

## 4. Lat Pulldown (V Handle)

### Weight
- 11 lbs

### Working Sets
- 3 sets

### Notes
- Ban đầu khó cảm nhận xô
- Sau khi:
  - giảm lực bóp handle
  - focus kéo bằng khuỷu tay
  - squeeze bottom
- Bắt đầu cảm nhận xô rõ

### Important Cue
> “Kéo khuỷu tay xuống túi quần”

### Form Notes
- Lean back nhẹ (~10–15°)
- Không đu người
- Handle xuống upper chest
- Eccentric chậm

### Major Milestone
- Lần đầu cảm nhận xô rõ ràng trong lat pulldown

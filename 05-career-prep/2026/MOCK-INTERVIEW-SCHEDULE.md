# Mock Interview Schedule — 3 Weeks

**Total Sessions:** 6 (2 per week)  
**Duration:** 30-60 minutes per session  
**Format:** Self-practice with AI or record yourself

---

## Week 1: Foundation (May 21-27)

### Session 1: Self-Introduction + Motivation
**Date:** Day 2 (May 22, Thursday)  
**Duration:** 30 minutes  
**Focus:** Basic introduction, why BrSE, career goals

**Questions to Practice:**
1. 自己紹介をお願いします。(Please introduce yourself)
2. なぜBrSEになりたいですか？(Why do you want to become a BrSE?)
3. あなたの強みは何ですか？(What are your strengths?)
4. QAからBrSEへの転職理由は？(Why transition from QA to BrSE?)
5. 日本語はどのくらいできますか？(How is your Japanese level?)

**Preparation:**
- [ ] Write answers in JP/EN/VI
- [ ] Practice speaking out loud
- [ ] Record yourself (optional)
- [ ] Time yourself (should be concise)

**Success Criteria:**
- Clear, confident self-introduction (2-3 minutes)
- Can explain motivation naturally
- No long pauses or "umm..."

---

### Session 2: KINKEN Overview + Your Role
**Date:** Day 5 (May 25, Sunday)  
**Duration:** 45 minutes  
**Focus:** Project overview, your contributions, technical understanding

**Questions to Practice:**
1. KINKENプロジェクトについて説明してください。(Explain the KINKEN project)
2. あなたの役割は何でしたか？(What was your role?)
3. プロジェクトで一番難しかったことは？(What was the most challenging part?)
4. どのような技術を使いましたか？(What technologies did you use?)
5. QAとして、どのようにバグを見つけましたか？(As QA, how did you find bugs?)

**Preparation:**
- [ ] Review KINKEN knowledge base
- [ ] Prepare 3-minute project overview
- [ ] List 3 key contributions
- [ ] Prepare 1-2 bug examples

**Success Criteria:**
- Can explain KINKEN clearly in 3-5 minutes
- Can describe technical stack
- Can give concrete examples

---

## Week 2: Application (May 28 - Jun 3)

### Session 3: Technical Deep Dive (ETL + Search)
**Date:** Day 9 (May 29, Thursday)  
**Duration:** 60 minutes  
**Focus:** Deep technical questions on weak areas

**Questions to Practice:**
1. ETLパイプラインについて詳しく説明してください。(Explain the ETL pipeline in detail)
2. Elasticsearchの検索動作はどうなっていますか？(How does Elasticsearch search work?)
3. Pickup ModeとNormal Modeの違いは？(What's the difference between Pickup and Normal mode?)
4. データフローを最初から最後まで説明してください。(Explain the data flow from start to end)
5. パフォーマンス問題をどう見つけましたか？(How did you find performance issues?)

**Preparation:**
- [ ] Deep dive into ETL pipeline
- [ ] Understand ES query behavior
- [ ] Draw data flow diagram
- [ ] Prepare performance testing examples

**Success Criteria:**
- Can explain technical concepts clearly
- Can draw diagrams if needed
- No major gaps in understanding

---

### Session 4: BrSE Scenarios (Requirement Clarification)
**Date:** Day 12 (June 1, Sunday)  
**Duration:** 60 minutes  
**Focus:** Communication, requirement clarification, problem-solving

**Scenarios to Practice:**

**Scenario 1: Ambiguous Requirement**
> Client says: "検索結果をもっと良くしてください。" (Make search results better)
> 
> Your task: Ask clarifying questions to understand what "better" means

**Scenario 2: Conflicting Requirements**
> GW team wants feature A, MOR team says it's technically difficult
> 
> Your task: Bridge communication, find compromise

**Scenario 3: Bug vs Feature**
> Client reports: "検索が遅い" (Search is slow)
> 
> Your task: Investigate, clarify, and communicate findings

**Preparation:**
- [ ] Practice asking clarifying questions
- [ ] Prepare communication templates
- [ ] Think about past examples
- [ ] Practice translating technical → non-technical

**Success Criteria:**
- Can ask good clarifying questions
- Can bridge technical/non-technical communication
- Can propose solutions

---

## Week 3: Polish (Jun 4-10)

### Session 5: Full Mock Interview (Technical + Behavioral)
**Date:** Day 16 (June 6, Friday)  
**Duration:** 90 minutes  
**Focus:** Realistic full interview simulation

**Interview Structure:**
1. **Self-introduction** (5 min)
2. **Project deep dive** (20 min)
3. **Technical questions** (30 min)
4. **BrSE scenarios** (20 min)
5. **Behavioral questions** (10 min)
6. **Your questions** (5 min)

**Questions to Practice:**

**Technical:**
- Explain KINKEN architecture
- How does search work?
- What testing did you do?
- How did you ensure quality?

**Behavioral:**
- Tell me about a time you found a critical bug
- How do you handle tight deadlines?
- Describe a conflict with a team member
- What's your biggest weakness?

**BrSE-Specific:**
- How would you handle language barriers?
- Give an example of clarifying requirements
- How do you prioritize tasks?

**Preparation:**
- [ ] Review all previous sessions
- [ ] Prepare STAR format answers (Situation, Task, Action, Result)
- [ ] Practice full flow without stopping
- [ ] Time yourself

**Success Criteria:**
- Complete interview without major gaps
- Confident and natural communication
- Can handle unexpected questions

---

### Session 6: Final Practice (Realistic Scenario)
**Date:** Day 19 (June 9, Monday)  
**Duration:** 60 minutes  
**Focus:** Final polish, address weak areas

**Custom Focus Based on Week 1-2 Performance:**
- If weak in technical: Focus on technical deep dive
- If weak in communication: Focus on BrSE scenarios
- If weak in Japanese: Focus on Japanese-only interview

**Questions to Practice:**
- Review questions you struggled with in previous sessions
- Add new questions based on job descriptions you're targeting
- Practice explaining mini-KINKEN project

**Preparation:**
- [ ] Review notes from all previous sessions
- [ ] List 3 weakest areas
- [ ] Prepare improved answers
- [ ] Final confidence check

**Success Criteria:**
- Noticeable improvement from Session 1
- Confident in all areas
- Ready for real interview

## Mock Interview Best Practices

### Before Each Session
1. Review relevant knowledge base sections
2. Prepare answers in writing first
3. Set up recording (phone/laptop)
4. Find quiet space
5. Dress professionally (helps mindset)

### During Session
1. Speak out loud (don't just think)
2. Time yourself
3. Don't stop to correct mistakes (note them for later)
4. Practice in target language (JP for Japanese companies)
5. Record yourself if possible

### After Each Session
1. Review recording (if available)
2. Note what went well
3. Note what needs improvement
4. Update knowledge base if gaps found
5. Plan practice for next session

## Tips for Success

### Language Switching
- Practice answering same question in JP/EN/VI
- Know which language to use when
- Don't mix languages in one answer (unless asked)

### STAR Format (Behavioral Questions)
- **S**ituation: Set the context
- **T**ask: Explain your responsibility
- **A**ction: Describe what you did
- **R**esult: Share the outcome

### Technical Explanations
- Start high-level, then go deeper if asked
- Use analogies for complex concepts
- Draw diagrams if helpful
- Check if interviewer is following

### Confidence Building
- Practice makes perfect
- Record yourself to see improvement
- Celebrate small wins
- Remember: you already have the knowledge, just need to communicate it

## Emergency Prep (If Time is Short)

If you fall behind schedule, prioritize:
1. **Session 1** (Self-intro) - MUST DO
2. **Session 3** (Technical) - MUST DO
3. **Session 5** (Full mock) - MUST DO
4. Sessions 2, 4, 6 - Do if time allows

Minimum viable prep: 3 sessions covering basics, technical, and full mock.
